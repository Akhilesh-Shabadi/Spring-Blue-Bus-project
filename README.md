# 🚌 Spring Blue Bus Project

A Spring Boot-based web application designed to manage bus transportation services. This project provides a backend system for booking, scheduling, and managing bus routes, passengers, and ticketing.

## 🚀 Features

- User registration and login
- Bus route management
- Ticket booking and cancellation
- Admin dashboard for managing buses and schedules
- RESTful APIs for frontend integration
- Secure authentication using Spring Security
- Database integration with JPA/Hibernate

## 🛠️ Tech Stack

- **Backend Framework**: Spring Boot
- **Security**: Spring Security
- **Database**: MySQL / H2 (for development)
- **ORM**: Hibernate / JPA
- **Build Tool**: Maven
- **IDE**: IntelliJ IDEA / Eclipse

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Akhilesh-Shabadi/Spring-Blue-Bus-project.git

2. Navigate to the project directory:
- **cd Spring-Blue-Bus-project**

3. - Build the project using Maven:
- **mvn clean install**

4. Run the application:
- **mvn spring-boot:run**

5. Access the application at:
- **http://localhost:8080**

## 🧪 Testing
- Unit and integration tests can be run using:
- **mvn test**
